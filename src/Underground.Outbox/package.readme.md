Underground.Outbox is a .NET library that provides an implementation for the [transactional outbox pattern](https://microservices.io/patterns/data/transactional-outbox.html).  
It provides an Outbox as well as an Inbox.

Requires .NET 10 and, for the source generator, .NET SDK 10.0.400 or newer (Roslyn 5.9).

Read the documentation [here](https://github.com/underground-dotnet/outbox).
